# Security Policy 🛡️

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

Security of user string sessions, bot tokens, and database credentials is our top priority.

If you discover a security vulnerability within **WAIFUSCRPER**, please DO NOT open a public issue.

Instead:
1. Contact the maintainer directly via GitHub Security Advisory or Telegram.
2. Provide a detailed summary with steps to reproduce the issue.
3. We will acknowledge receipt within 48 hours and work on a fix promptly.

---

## Best Practices for Users
- Never commit your `.env` file or export your `STRING_SESSION` to public forums.
- Always run the scraper userbot using a dedicated, secondary Telegram account.
- Restrict MongoDB access with IP whitelists and complex passwords.
