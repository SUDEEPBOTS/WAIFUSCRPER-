🔄 Real-Time Scraping Data Flow

        

        

          
[1] Telegram Channel

          
    └── MTProto Userbot Client (get_chat_history stream)

          

          
[2] Caption Normalization & Tokenizer

          
    ├── Unicode NFKD normalization (replaces stylized unicode)

          
    ├── Regex match: ID + Name, Rarity keyword, Added By tag

          
    └── Sequential ID generation if unassigned in caption

          

          
[3] Multi-Hoster Image Relay

          
    ├── Download telegram photo in-memory buffer

          
    ├── Primary: Catbox.moe (3 retries with 30s timeout)

          
    └── Fallback: ImgBB API (base64 multipart)

          

          
[4] MongoDB Motor Atomic Storage

          
    ├── Duplicate check via waifu_exists(waifu_id)

          
    └── Insert structured BSON doc with UTC timestamp
